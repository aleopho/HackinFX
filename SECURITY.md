# Security reports

Do not put credentials, private report content or unredacted system data in a public issue. For a suspected vulnerability, use GitHub's private vulnerability reporting for this repository if enabled; otherwise ask the maintainer for a private reporting channel without posting exploit details or personal data publicly. No security contact email is published here.

The shared catalog contains untrusted user claims and must remain informational. It cannot select an unknown driver module or deliver executable code. Preserve prepared statements, request-size limits, allowlisted payloads, receipt validation and exact PCI guards. Network rate limits are not authentication or proof of honest hardware observations.
