# User guide

## Installation

Use the DMG linked in README/Releases. Quit earlier copies, drag the app to Applications, eject the image and launch the installed copy. Install the required NullMoth driver separately following upstream guidance; HackinFX does not install a kernel driver. A working system Python 3 is also required.

The app is ad-hoc signed without Developer ID/notarization. Downloaded copies may prompt macOS security checks. HackinFX does not change those protections. See Apple's normal guidance for opening software from a developer you trust rather than disabling system protection globally.

## First run

A short intro is followed by a visible passive scan. Supported cards without a matching full local profile begin a seven-stage test. Observe the physical GPU throughout, including the final Wave interval. The test can be stopped.

Select **Everything worked — save profile** only when every displayed color/effect visibly worked. A partial response or no light opens the feedback/report path. Successful setup saves the local profile; the sharing checkbox determines whether a minimal community confirmation is queued. Saved matching profiles skip later lighting tests, but each launch still performs passive inventory. Hardware/OS/driver changes can require a new test.

The identity section lets you correct a generic/inaccurate name or enter missing manufacturer/model details. PCI IDs remain those detected by the scanner. User-supplied identity is marked as such in the database. Unknown cards cannot be activated by entering a supported model name.

## Studio and menu bar

Choose Static, Gradient, Spectrum, Breathing or Wave, adjust available colors/brightness/speed, then Apply. Gradient uses three controller zones. Off is available. The preview is a schematic, not a live readback of LEDs. Effects are generated by the controller and can remain active when the app quits.

Window close keeps HackinFX running in the menu bar and hides its Dock presence. Open Lighting restores the window. Quit HackinFX exits explicitly. Hardware/profile summary and sharing controls are on Hardware; test details use a separate dialog.

## Something failed

Use Hardware → scan/export or the test feedback dialog. Describe whether all lighting is dark, particular colors/zones fail, an effect is wrong, or commands report errors. Include exact board model/revision when known. Review the JSON, then send privately; retain an export if offline. A missing acknowledgement is not a successful submission. Community confirmations are queued for automatic retry; private troubleshooting reports require the explicit Send action.

A card may be detected correctly while its lighting is unsupported. The report is useful for investigation but does not make the RGB implementation automatic. Report a generic/spoofed registry name using the correction fields.

For a reproducible public issue, provide app version, approximate macOS/driver versions, card identifiers and behavior with personal details removed. Do not paste credentials, full device trees or unrelated system logs.
