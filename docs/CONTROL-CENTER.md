# Control Center

The Control Center is the main HackinFX 2.1.1 Lighting Studio, covering Lighting,
Devices, Canvas and Effects. GPU Lab, Diagnostics and Credits are advanced tools;
Settings includes launch at login and software updates.

The bundled OpenRGB engine and native adapters share one local Core. Ready
devices are selected on startup and set to white. Changes apply automatically.
Canvas chooses mirrored group output or spatial placement; Effects edits palette
and animation parameters and saves looks. This replaces the old duplicated
Scenes/Layout workflow.

See [everyday use](USER-GUIDE.md), [architecture and synchronization](ARCHITECTURE.md)
and [actual device evidence](COMPATIBILITY.md). RAM remains under development,
and identity catalog matches alone never authorize lighting writes.
